What I'm Building

Camply

Campus Mobility & Errand Platform

A campus-focused platform designed to make everyday tasks easier for university students.

- Campus ride requests.
- Errand requests and item purchasing.
- Local delivery coordination.

Vision: One app, every campus task.

StudentPal

Academic Resource Platform

An academic resource platform designed for the Faculty of Computing at Adekunle Ajasin University, Akungba-Akoko.

- Academic notes and learning resources.
- Assignments and announcements.
- Academic calendar.
- Opportunities and student community.
- AI-powered resource discovery exploration.

ServeFlow

Restaurant Ordering API

An API-first product exploring how technology can improve restaurant ordering and service workflows.

- Digital menu and order management.
- Restaurant-specific data and permissions.
- Order status and workflow management.
- Payment status tracking.
- Subscription-based SaaS architecture.

Project Akungba Explorer

Digital Geographic Exploration

An exploration of interactive geographic information and digital mapping focused on Akungba-Akoko, Ondo State, Nigeria.

- Geographic information.
- Interactive mapping.
- 3D exploration experiences.
