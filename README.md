"04 — HOW I DEBUG"

Something broke.
      │
      ▼
Don't panic.
      │
      ▼
Reproduce it.
      │
      ▼
Read the error.
      │
      ▼
Find the boundary.
      │
      ▼
Inspect the data.
      │
      ▼
Form a hypothesis.
      │
      ▼
Test the hypothesis.
      │
      ▼
Fix the root cause.
      │
      ▼
Test again.
      │
      ▼
Document what happened.

Because:

«Debugging isn't guessing.»

It's investigation.
